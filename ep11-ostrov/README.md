# Серия 11 — «Что, если ты один на острове?» (гайд со сверкой запасов)

Новое: в конце не баллы, а **сверка запасов** — вода 7 л из 10 (7/10), огонь 1/1, еда 3 дня из 7 (3/7),
укрытие 1/1, сигнал 1/1 → «шансы выжить 80%». Голос рассказчика — Светлана, +15% скорости.
Поворот без двойника: остров оказывается спиной гигантского живого существа.

Вертикальный ролик 1080×1920, 30 к/с, ~95 с. Видеоряд — код (Python + Cairo), звук — синтез, озвучка — Edge TTS.

Готовый файл: `out/ep11-ostrov.mp4` · Пересборка: `./build.sh`

## Сцены
Пробуждение на пляже → вода (дождь в листья, морскую не пить) → огонь → укрытие выше прилива → еда (кокосы, мидии,
рыба) → SOS из камней → сверка запасов → 80% → на седьмой день небывалый отлив → песок тёплый и «дышит» →
из воды у рифа поднимается огромный глаз и моргает → камера отлетает: остров — панцирь существа, которое плывёт →
«ЧАСТЬ 2: Куда оно плывёт?»

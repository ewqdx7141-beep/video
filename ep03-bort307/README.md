# Серия 3 — «Что, если все в самолёте уснули, кроме тебя?» (Борт 307)

Вертикальный ролик 1080×1920, 30 к/с, около 91 секунды. Видеоряд — код (Python + Cairo), звук — синтез (numpy/scipy),
озвучка — Edge TTS `ru-RU-DmitryNeural`. Реплики диспетчера (`R|` в `script/voice.txt`) озвучены тем же голосом,
что и рассказчик, и пропущены через радиофильтр — в финале выясняется, что это был голос героя.

Готовый файл: `out/ep03-bort307.mp4` · Пересборка: `./build.sh`

# Серия 42 — «Что, если ты в темнице XVI века?» (Средневековье, исторический гайд)

Каменная темница (кладка с мхом, решётчатое окошко и лунный луч, факелы с пламенем, цепи, солома, миска, крыса,
капли), суд (гобелены, герб, судья в чёрной шапочке, писарь, стражник с алебардой, свечи, массовка горожан),
поручитель, закон 1532 года («признание под пыткой надо повторить без пытки»), допросная с дыбой — показана только
тенью на стене; писарь и свиток с тремя одинаковыми показаниями; колодки на городской площади с фахверковыми домами,
колокольней, брусчаткой и толпой, кидающей гнилые овощи; двое свидетелей. Сверка: поручитель 1/1, признания 0,
слова 3/3, колодки 3 часа, свидетели 2. Поворот (правда): «Железная дева» в подвале суда — но историки не нашли
доказательств её применения; её, скорее всего, собрали в XIX веке для музеев (зал с посетителями в цилиндрах,
табличка) → «ЧАСТЬ 2: Какие ещё страшилки о Средневековье — ложь?»
Голос — Дмитрий (мужской, низкий, медленнее). Музыка — средневековая: бурдон, лютня (дорийский лад), рамочный
барабан, церковный колокол; после поворота — тёмный гул.

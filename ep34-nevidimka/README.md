# Серия 34 — «Что, если ты стал невидимым на один день?» (челлендж со сверкой)

Сценарий — `../SCENARIOS.md` №34. Ванная с плиткой, зеркалом (в нём — только парящая щётка с пеной), стаканом с пастой,
мылом и полотенцем; герой-невидимка показан зрителю еле заметным мерцающим силуэтом; улица с камерой наблюдения,
прохожими и собакой, лающей в пустоту, таймер до полуночи; «пустой костюм» (худи, джинсы, кепка, очки) и испуганные
прохожие; ювелирная витрина и кошелёк на прилавке — перечёркнуто; вход в кафе следом за прохожей; яблоки
поднимаются в пакет бабушки, придержанная дверь, счётчик помощи; часы 23:50 и комната с кроватью.

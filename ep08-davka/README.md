# Серия 8 — «Что делать, если ты попал в давку?» (формат «гайд»)

Новый формат: ситуация → 5 шагов с плашками «ШАГ N» (что делать / чего не делать) → проверка по шагам с баллами
(+20 за шаг, итог 100/100) → «ты всё сделал правильно… слишком правильно» → поворот и крючок на часть 2.
Советы — реальные правила безопасности в толпе (руки у груди, двигаться с толпой наискосок, не наклоняться за вещами,
упал — вставай или на бок и закрой голову, береги силы, держись подальше от ограждений).

Вертикальный ролик 1080×1920, 30 к/с, ~90 с. Видеоряд — код (Python + Cairo), звук — синтез, озвучка — Edge TTS.

Готовый файл: `out/ep08-davka.mp4` · Пересборка: `./build.sh`

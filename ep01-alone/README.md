# Эпизод 1 — «Что, если ты остался один на Земле?»

Вертикальный ролик 1080×1920, 30 к/с, около 93 секунд. Весь видеоряд нарисован кодом (Python + Cairo),
звук синтезирован кодом (numpy/scipy), озвучка — Edge TTS (голос ru-RU-DmitryNeural).

Готовый файл: `out/ep01-alone.mp4`

## Как пересобрать
```bash
./build.sh
```

## Файлы
| Файл | Что делает |
|---|---|
| `script/voice.txt` | текст озвучки, одна строка = одна сцена |
| `tts.py` | озвучка каждой строки + тайминги слов (`audio/lines.json`); `python3 tts.py 9` — перегенерировать только строку 9 |
| `common.py` | таймлайн: паузы между фразами, переходы, звуковые события (шаги, вибрация…) |
| `draw.py` | герой (эмоции, позы), массовка, манекены, тень незнакомца, город, еда, телефон |
| `render.py` | 13 сцен, камера, переходы, субтитры, заголовок-хук; `--stills shots` — контрольные кадры |
| `audio.py` | микс: голос, музыка по частям (тревога → веселье → одиночество → ужас), эффекты, −14 LUFS |
| `sheet.py` | контактный лист из кадров для проверки |

## Сцены
0 спальня, хук → 1 улица и автобус → 2 кафе, недописанное «Я почти дома» → 3 толпа + «Удалить всех людей?» →
4 стена телевизоров → 5 весёлая неделя (тележка, спорткар, люкс, гора еды) → 6 ночная тишина →
7 манекен (один на фоне поворачивает голову) → 8 «Я ЗДЕСЬ» на крыше → 9 телефон вибрирует →
10 «Номер скрыт» → 11 «Не выключай свет. Они думают, что забрали всех» → 12 шаги по подъезду, ноги под дверью,
свет гаснет → «ЧАСТЬ 2».

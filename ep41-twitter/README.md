# Серия 41 — «Что, если тебе звонит „техподдержка“?» (взломы, реальная история 2020 года)

Гайд против телефонного фишинга: положи трубку и перезвони сам по внутреннему справочнику, не вводи пароль по чужой
ссылке (поддельный адрес страницы входа), не называй код из СМС, используй аппаратный ключ, сообщи в службу
безопасности. Детали: опенспейс с панорамными окнами и городом, столы с мониторами, массовка с наушниками и кофе,
бейдж сотрудника, экран входящего звонка «IT», справочник с номерами, фейковая страница входа, СМС с кодом, ключ в USB.
Сверка: пароль 0, код 0, ключ 1/1, сообщения 1, взломано 0. Поворот (правда): 15 июля 2020 года так звонили
сотрудникам крупной соцсети — кто-то ответил; через несколько часов аккаунты Обамы, Байдена, Маска и Гейтса
публикуют «пришлите биткоин — верну вдвое»; мошенники собирают больше $100 000; через две недели полиция Флориды
арестовывает организатора — ему 17 лет → «ЧАСТЬ 2: Как подросток взломал соцсеть?»
Голос — Дмитрий (мужской, ниже), новая музыка — тёмный кибер-синт 112 BPM с битом, басом и арпеджио.

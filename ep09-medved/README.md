# Серия 9 — «Что делать, если ты встретил медведя?» (формат «гайд»)

Ситуация → 5 шагов с плашками → проверка 100/100 → «слишком правильно» → поворот.
Советы для встречи с бурым медведем: не бежать, не смотреть прямо в глаза, казаться больше и говорить спокойно
низким голосом, медленно отступать, не поворачиваясь спиной; при нападении — лечь на живот и закрыть шею руками.

Вертикальный ролик 1080×1920, 30 к/с, ~91 с. Видеоряд — код (Python + Cairo), звук — синтез, озвучка — Edge TTS.

Готовый файл: `out/ep09-medved.mp4` · Пересборка: `./build.sh`

## Поворот
Медведь уходит. Из-за деревьев выходит егерь: «Этот медведь никогда никого не отпускает. Значит, ты ему нужен живым.»
Рядом с твоими следами на снегу — ещё одни, человеческие, босые, и они ведут к твоей палатке → «ЧАСТЬ 2: Кто в твоей палатке?»

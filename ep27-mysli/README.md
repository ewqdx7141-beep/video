# Серия 27 — «Что, если ты можешь читать мысли один день?» (челлендж со сверкой)

Сценарий — `../SCENARIOS.md` №27. Облачка мыслей над массовкой с иконками и фразами («опоздаю на планёрку», «купить
молоко», «выключил ли утюг?»), лифт с соседкой («Доброе утро!» / «опять топал всю ночь»), офис с коллегами,
вагон метро с десятками облачков, которые размываются, когда герой надевает наушники (волны музыки), девочка
и кошелёк под лавкой, мама на кухне с закрытым на замок облачком, осенний парк на закате с аллеей и фонарями,
гостиная с диваном, книгами и лампой. Сверка: помог 7, выдал себя 0, мысли близких 0, наушники 1/1, тишина 40 мин.
Поворот: ночью чужая мысль «Наконец-то он меня слышит» звучит из головы героя; отражение в окне с другой мимикой,
«20 лет внутри — поменяемся?» → «ЧАСТЬ 2: Кто живёт в твоей голове?» Голос — Светлана +15%.
